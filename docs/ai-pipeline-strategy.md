# Newsense AI 멀티 모델 협업 파이프라인 전략

Newsense의 핵심 가치는 AI가 만들어내는 요약본, 퀴즈, 카테고리 분류의 품질입니다.
제한된 예산 30,000 크레딧 안에서 품질을 극대화하기 위해 작업 성격에 따라 모델을 나누어 쓰는 멀티 모델 협업 파이프라인을 운영합니다.

## 1. 가성비 극대화 멀티 모델 구성

단일 고가 모델에 모든 연산을 몰아주지 않고, 작업 성격에 따라 Nano, Mini, Pro급 모델을 조합합니다.
기사당 평균 목표 비용은 약 17 크레딧입니다.

| 역할 | 할당 모델 | 예상 크레딧 | 최적화 사유 |
| --- | --- | ---: | --- |
| 임베딩 | `text-embedding-3-large` | 0.01 | RAG 기반 단어 검색과 근거 청크 검색에 사용합니다. `gemini-embedding-2` 대비 저렴하면서 검색 품질을 확보합니다. |
| 1단계: 팩트 추출 | `gemini-2.5-flash-lite` | 1.0 | 긴 뉴스 원문에서 수치 데이터, 주요 명사, 핵심 이벤트를 빠르게 정리합니다. |
| 2단계: 요약, 분류, 기업 추출 | `gpt-4o-mini` | 2.0 | Structured Outputs와 JSON Schema 기반 응답에 강해 기사 메타데이터 저장 안정성이 높습니다. |
| 3단계: 퀴즈 출제 | `o3-mini` | 10.0 | 기사 근거 기반 추론, 인과관계 문항 생성, RAG 검증에 집중 투입합니다. |
| 4단계: 자가 교정 | `gpt-4o-mini` | 2.0 | 생성된 퀴즈의 정답 중복, 근거 부재, 선택지 품질을 검증하고 문제가 있을 때만 재출제를 유도합니다. |

## 2. 기사 정제 및 3줄 요약

기사 정제는 토큰 낭비와 프롬프트 혼동을 줄이기 위한 선행 단계입니다.
현재 `ContentCleaner` 구현 범위는 HTML 태그 제거, 유니코드/일반 공백 정규화, 기자 이메일 제거, 저작권·재배포 금지 문구 제거, 일반적인 기자명·배포처 서명 제거입니다.
광고성 문구, 반복 푸터, 언론사별 메타 텍스트 제거는 목표 범위로 두되 아직 공통 규칙에 포함하지 않습니다.
해당 항목은 기사 본문 문장을 오탐 삭제할 수 있으므로 언론사별 패턴이나 샘플 기반 검증을 갖춘 뒤 별도 규칙으로 추가합니다.

요약 생성은 다음 기준을 지킵니다.

- 본문 속 중요한 정량 수치, 예를 들면 금리, 환율, 지수, 증감률, 예산 규모 중 최소 1개 이상을 포함합니다.
- "이 뉴스는 ~에 대한 내용입니다"처럼 정보 밀도가 낮은 상투적 표현을 금지합니다.
- 각 줄은 주어, 목적어, 서술어가 분명한 문장으로 끝냅니다.
- 3줄 요약은 기사 근거에 기반해야 하며, 본문에 없는 전망이나 투자 판단을 추가하지 않습니다.
- 1,000자 미만 기사에는 자동 AI 요약을 생략하고, 관리자 페이지에서 수동 생성 여부를 판단할 수 있게 합니다.

## 3. 퀴즈 품질 극대화

퀴즈 생성은 Generator-Critic 구조로 운영합니다.
생성 모델은 교육학적 문항을 만들고, 검증 모델은 기사 근거와 정답 품질을 확인합니다.

### 문항 구성

1. 개념 이해 문항
   - 기사와 연관된 경제 용어를 기재부 경제사전 또는 내부 용어 사전 기준으로 응용합니다.
   - OX 형식으로 개념 적용 여부를 빠르게 확인합니다.

2. 사실 확인 문항
   - 본문 속 정량적 사실이나 통계 수치의 진위를 묻습니다.
   - 객관식 형식으로 출제하고, 오답은 단순 임의 숫자가 아니라 기사에 등장한 다른 수치나 유사 개념을 활용합니다.

3. 인과 추론 문항
   - 금리, 환율, 물가, 부동산, 주식시장 등 경제 현상 간 영향을 묻습니다.
   - 기사 본문과 RAG 근거 청크를 함께 사용해 고난이도 객관식 문항으로 구성합니다.

### 오답 설계

- 오답은 명백히 말이 안 되는 선택지가 아니라 기사 본문 속 다른 핵심 키워드와 숫자를 섞어 변별력을 높입니다.
- 정답과 표현만 다른 중복 선택지를 금지합니다.
- 모든 선택지는 같은 문체와 비슷한 길이를 유지합니다.

### 자가 교정 루프

검증 모델은 다음 항목을 확인한 뒤 저장 여부를 결정합니다.

- 정답이 하나만 존재하는지
- 기사 본문 또는 RAG 근거 청크로 설명 가능한지
- 선택지 중 중복 정답이나 모호한 표현이 없는지
- 난이도와 문항 목적이 일치하는지

검증 실패 시에는 생성 단계로 피드백을 돌려 재출제를 요청합니다.
재시도 횟수는 비용 보호를 위해 제한하고, 최종 실패 시 해당 기사 퀴즈 생성 실패 로그를 남깁니다.

## 4. 카테고리 및 난이도 분류 일관성

카테고리는 하네스 기준의 5개 displayName만 사용합니다.

| 카테고리 | 판정 기준 |
| --- | --- |
| 거시경제 | 금리, 물가, 성장률, 고용, 소비, GDP 등 경제 전반 지표가 중심인 기사 |
| 금융/투자 | 주식, 채권, 펀드, 금융상품, 투자시장, 금융기관 이슈가 중심인 기사 |
| 정책/제도 | 정부 정책, 법령, 규제, 지원제도, 세제 변화가 중심인 기사 |
| 기업/산업 | 특정 기업, 산업 구조, 실적, 공급망, 기술 변화가 중심인 기사 |
| 글로벌경제 | 해외 경제, 국제 금융, 주요국 정책, 환율, 무역 이슈가 중심인 기사 |

난이도는 다음 기준으로 분류합니다.

| 난이도 | 판정 기준 |
| --- | --- |
| 초급 | 핵심 경제 개념이 1~2개이고, 기사 이해에 별도 배경지식이 거의 필요하지 않은 경우 |
| 중급 | 여러 경제 지표 또는 정책 효과를 함께 이해해야 하는 경우 |
| 고급 | 복합 인과관계, 시장 파급효과, 제도적 맥락, 수식 또는 전문 용어 밀도가 높은 경우 |

프롬프트에는 각 경계 사례를 few-shot으로 포함해 분류 흔들림을 줄입니다.
특히 금융/투자와 기업/산업, 거시경제와 정책/제도 사이의 경계를 명확히 정의합니다.

## 5. 운영 원칙

- 모든 AI 응답은 저장 전에 JSON Schema 검증을 통과해야 합니다.
- 기사 원문이 짧거나 노이즈가 많으면 자동 생성보다 관리자 수동 검토를 우선합니다.
- 비용 초과 방지를 위해 단계별 실패 횟수와 재시도 횟수를 제한합니다.
- 퀴즈와 요약에는 투자 조언처럼 해석될 수 있는 문장을 넣지 않습니다.
- 관리자 페이지에서 요약 누락 기사와 본문 길이를 확인할 수 있어야 합니다.

## 6. 향후 확장

- 모델별 비용과 실패율을 로그로 축적해 기사당 평균 비용을 추적합니다.
- 요약 품질, 퀴즈 정답률, 사용자 리뷰 데이터를 기반으로 프롬프트를 주기적으로 개선합니다.
- 카테고리별 품질 편차가 큰 경우 few-shot 예시를 카테고리별로 분리합니다.
